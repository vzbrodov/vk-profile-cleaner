# Консольный режим

Установка из корня проекта:

```bash
make setup
.venv/bin/vk-cleaner-cli --help
```

CLI использует то же ядро и базу, что и GUI. Токен вводится скрыто в терминале;
не передавайте его в аргументах командной строки. Закройте выполняющуюся операцию
GUI перед запуском удаления через CLI.

## Анализ сообщений

Один диалог:

```bash
.venv/bin/vk-cleaner-cli scan --peer-id 123456 --date-from 2024-01-01 --date-to 2024-12-31 --dry-run
```

Несколько — повторите `--peer-id`. Для всех доступных диалогов используйте `--all`.
Конечная дата включительна; часовой пояс по умолчанию `Europe/Moscow`, изменить
его можно через `--timezone`. Пример:

```bash
.venv/bin/vk-cleaner-cli scan --all --date-from 2024-01-01 --date-to 2024-12-31 --timezone Europe/Moscow
```

`scan` всегда только анализирует и сохраняет задание, даже без `--dry-run`.
В конце выводятся ID задания и digest подтверждения. Сейчас CLI выбирает все
найденные свои сообщения; индивидуальное исключение доступно в GUI.

## Удаление и возобновление

Подставьте ID задания и digest из результата анализа:

```bash
.venv/bin/vk-cleaner-cli run --job-id ID --confirm DIGEST
.venv/bin/vk-cleaner-cli resume --job-id ID --confirm DIGEST
```

Эти команды удаляют сообщения для всех. Владелец токена должен совпадать
с аккаунтом задания. Подтверждённые элементы не повторяются; неизвестный
результат запроса блокирует автоматическое продолжение. Ctrl+C прерывает процесс;
при повторном запуске отправленный незавершённый пакет требует проверки.

## Отчёт и CSV

```bash
.venv/bin/vk-cleaner-cli report --job-id ID
.venv/bin/vk-cleaner-cli export --job-id ID --output messages.csv
```

Отчёт содержит счётчики состояний: `confirmed` — подтверждено API, `failed` —
отказ, `pending` — ещё не отправлено, `unknown` — результат неизвестен.
CSV содержит `peer_id, peer_name, message_id, date, text_snippet, cmid`.
Фрагменты сообщений после завершения задания очищаются; для сохранения текста
экспортируйте список перед удалением.

## Демонстрация

Используйте отдельную базу, чтобы не смешивать тестовые данные с реальными:

```bash
.venv/bin/vk-cleaner-cli --demo --database /tmp/vk-cleaner-demo.sqlite3 scan --all --date-from 2020-01-01 --date-to 2030-12-31
```

Для последующих команд задавайте те же `--demo --database` перед именем команды.

Коды выхода: 0 — успех, 1 — ошибка, 2 — неверные аргументы,
3 — частичный/неизвестный результат, 130 — прерывание.

## Проверка доступа без удаления

[Отдельная диагностика API](api-check.md) проверяет токен, список диалогов
и образец истории. Она не проверяет возможность удаления для всех.

```bash
python3 tools/vk_probe.py --peer-id 123456
```
